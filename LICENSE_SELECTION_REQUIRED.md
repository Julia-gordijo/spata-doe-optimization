# Software license selection required

No software license has yet been applied to this repository. Without an explicit license, others may view the public code but do not automatically have permission to reuse, modify, or redistribute it.

Before making the repository public, the authors should confirm the license with all code contributors and applicable institutional requirements.

Common options for research software include:

- **MIT License:** short and permissive; allows reuse with attribution and the license notice.
- **BSD 3-Clause License:** permissive and includes a non-endorsement clause.
- **GNU GPLv3:** requires redistributed derivative software to remain under the GPL.

After choosing a license, delete this file and add the official license text as a root-level file named `LICENSE`.

The associated Zenodo dataset may use a separate license, such as CC BY 4.0. Creative Commons licenses are generally used for data and documentation rather than executable software.
